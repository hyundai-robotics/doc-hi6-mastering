## 1.2 접촉식 센서 기반 로봇 마스터링 기능

본 사용설명서는 `접촉식 센서 기반` 로봇 마스터링 기능에 대한 내용을 담고 있습니다.  
해당 마스터링 키트와 기능의 활용으로 보다 정밀한 보정이 가능합니다.

<br>

### 1.2.1. 시스템 환경
- **로봇** <br>- 마스터링 블록 장착 모델
- **Hi6 로봇 제어기** <br>- app 설치
- **마스터링 키트** <br>- 컨트롤러 + 전원

<br>

### 1.2.2. 동작 조건
- 로봇의 동작 모드는 `수동 모드`로 설정해야 합니다.
- `모터 온` 상태에서 동작을 수행할 수 있습니다.

<br>

### 1.2.3. 요약 과정
- 로봇의 각 축 별로 존재하는 V홈의 중점을 접촉식 센서로 찾은 후 해당 지점을 원점으로 보정하는 동작을 합니다.  

<br>

### 1.2.4. 전체 과정
1. `엔지니어 모드(R버튼 + 314)` 진입
2. 엔코더 옵셋 보정 - 육안 상  
3. 엔코더 옵셋 보정 - 플러그인 기반  
    (1) `마스터링 플러그인` 진입  
    (2) [대기 화면](../../02_about_kit/3-com_initialization/README.md)에서 `마스터링 대상 축 번호` 입력 > `확인`  
    (3) `마스터링 플러그인` 재진입  
    (4) 모터 온 > `1.엔코더 오프셋 이동` 버튼 클릭  
    (5) 센서 장착  
    (6) V홈 근처에 센서 팁이 위치했는지 확인  
    (7) `2.마스터링 시작` 버튼 클릭  
    (8) 완료 시 `확인` 클릭  
    (9) 센서 탈착  
    (10) 추가로 마스터링 해야하는 축이 있을 시 후 (1) 부터 재진행  
4. ⭐ 전 축 마스터링 완료 후 갱신된 `보정된 엔코더 원점`으로 이동 ⭐  
    - `시스템` > `3: 로봇 파라미터` > `4: 엔코더 옵셋` > `로봇 이동`  
    - `shift + 확인` > `확인`  
5. 마스터링 후 보정된 엔코더 옵셋 보정 여부 확인  
    - `보정된 엔코더` 값이 `엔코더 오프셋(이후)` 값과 동일한지 확인  
    - `현재 엔코더` 값이 `0x400000` 인지 확인
