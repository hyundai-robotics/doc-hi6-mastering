## 1.2 접촉식 센서 기반 로봇 마스터링 기능

본 사용설명서는 `접촉식 센서 기반` 로봇 마스터링 기능에 대한 내용을 담고 있습니다.  
해당 마스터링 키트와 기능의 활용으로 보다 정밀한 보정이 가능합니다.

<br>

### 1.2.1. 시스템 환경
- **로봇** <br>- 마스터링 블록 장착 모델
- **Hi6 로봇 제어기** <br>- app 설치
- **마스터링 키트** <br>- 컨트롤러 + 전원

<br>

### 1.2.2. 동작 조건
- 로봇의 동작 모드는 `수동 모드`로 설정해야 합니다.
- `모터 온` 상태에서 동작을 수행할 수 있습니다.

<br>

### 1.2.3. 요약 과정
- 로봇의 각 축 별로 존재하는 V홈의 중점을 접촉식 센서로 찾은 후 해당 지점을 원점으로 보정하는 동작을 합니다.  

<br>

### 1.2.4. 전체 과정
#### 1. 엔코더 옵셋 보정 - `육안 상`
- 1-a) 사용자가 V홈 또는 로봇에 장착된 스케일 바를 기준으로 TP로 조그를 진행합니다(기준점 세팅).  
- 1-b) 축 별(또는 전체 축)로 육안 상으로 맞춰진 위치에 대해 엔코더 오프셋 보정을 진행합니다.  
    - 엔코더 옵셋 설정 화면 진입  
        &rightarrow; TP > 엔지니어모드 진입(R: 314) > 2: 시스템 > 3: 로봇 파라미터 > 4: 엔코더 옵셋  
    - 엔코더 옵셋 초기화 진행  
        (1) 단일 축 대상인 경우  
            &rightarrow; 해당 축의 `보정된 엔코더 값` 클릭 > `단일 초기화` 클릭  > `shift + 확인` > `확인`  
        (2) 전체 축 대상인 경우    
            &rightarrow; `전체 초기화` 클릭 > `shift + 확인` > `확인`

#### 3. 엔코더 오프셋 보정 - `마스터링 플러그인 기반`    
- 3-a) 1.의 과정을 마친 후 마스터링 플러그인에 들어가서 센서가 장착된 축으로 `축 번호` 입력 후 확인   
- 3-b) `1.인코더 오프셋 이동` 버튼을 클릭합니다.  
- 3-c) 육안으로 맞춘 V홈에 맞게 로봇이 이동한 것을 확인하고 `2. 마스터링 시작` 버튼을 클릭합니다.  
- 3-d) 마스터링 진행      
    1) `시작점` 이동: 현재 위치를 기준으로 `-1.5도` 지점을 시작점으로 설정해 움직입니다.   
    2) `도착점` 설정: 시작점을 기준으로 `+3.0도` 지점을 도착점으로 설정합니다.   
    3) `정방향` 스캔: `시작점 -> 도착점` 방향으로 스캔을 진행합니다.   
    4) `역방향` 스캔: `도착점 -> 시작점` 방향으로 스캔을 진행합니다.   
- 3-e) `보정된 엔코더` 갱신   
    1) TP > 엔지니어모드 진입(R: 314) > 2: 시스템 > 3: 로봇 파라미터 > 4: 엔코더 옵셋  
    2) `단일` 또는 `전체` 초기화 클릭 (`단일`: 축 별 마스터링 시 / `전체`: 전체 축 마스터링 시)  
    2) `shift + 확인` > `확인`  
        &rightarrow; ❗ 주의 ❗ 해당 과정이 생략되면 제어기 재부팅 시 엔코더 오프셋 수치가 사라집니다.  

<br>

#### 4. 마스터링 후 엔코더 오프셋 보정 여부 확인  
(1) TP > 엔지니어모드 진입(R: 314) > 2: 시스템 > 3: 로봇 파라미터 > 4: 엔코더 옵셋  
(2) `로봇이동` 클릭   
(3) `보정된 엔코더`의 값들이 `마스터링 된 후의 엔코더 오프셋` 값들인지 확인.  
(4) 그 때의 현재 엔코더 값이 `0x400000` 값으로 설정되어있는지 확인.
